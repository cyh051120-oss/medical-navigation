# 就医准备助手（微信小程序）

一个帮你把「看诊前要准备的事」理顺的本机小程序：随手记下零散的健康信息，出门前整理成
一份条理清楚的就医摘要；需要时，再借助你自己电脑上的 AI 代理，把口语化的描述整理成
可读的要点。所有记录默认只存在你自己的手机上。

## 产品定位

看病前的那段时间常常手忙脚乱：想说的症状记不全，化验单上的字看不懂，想问医生的问题
一转身就忘。本小程序只专注一件事，把看诊前的准备做好：

- 在手机上随手记下症状、资料与想问的问题；
- 把散落在各处的信息收拢成一份可以带着走的就医摘要；
- 需要时用 AI 把口语化的描述整理成要点，或者帮你梳理可以留意的健康方向、日常建议，
  以及值得向医生确认的问题。

它不替你判断身体出了什么问题，也不替你做任何医疗决定。真正看病，仍然要由执业医务人员
当面完成。

## 能力清单

### 单页工作台与 8 个功能区

应用启动即进入**单页工作台（workspace）**：左侧导航在单页内切换下列 8 个功能区，
不重建页面、也没有整页导航动画，各功能区各自保留滚动位置，系统导航栏标题随之更新。
下列 8 个路由页同时保留为可直接打开的独立页面（深链/兼容），行为与视觉不变。

| 页面 | 作用 |
|---|---|
| 工作台（home） | 总览入口，按本机时间给出问候 |
| 个人档案（profile） | 年龄段、性别、过敏、长期用药、既往情况 |
| 症状时间线（symptoms） | 按时间记录症状原话、持续时长与影响 |
| 资料摘录（notes） | 化验单、检查报告等资料的文字摘录与来源日期 |
| 待问清单（questions） | 记下想问的问题，可勾选完成、按分组整理 |
| 就医摘要（brief） | 把上面的记录汇总成一份可导出的摘要 |
| AI 助手（ai） | 资料整理、问诊建议与问诊引导三种模式 |
| 设置（settings） | 字号、高对比、AI 开关、记忆管理、导出与清除 |

### 本地记录

- 记录写入微信本机存储的 `mhp_` 命名空间，包含 6 类内容：个人档案、症状、资料、待问、
  就医摘要、偏好记忆。
- 症状与资料可各带 1 个附件（照片等），附件会复制到小程序自己的本地文件目录，不上传。
- 设置页可一键导出全部文字记录；也可分两步确认后，清除所有本地记录、附件、本机导出文件与记忆。

### AI 三种模式

AI 只走你本机启动的代理（默认 `http://127.0.0.1:8787`），小程序不直接连外部服务：

- **资料整理（organize）**：把一段口语化原话整理成要点、可提取的信息、待补充项，以及
  可以问医生的问题。
- **问诊建议（consult）**：结合你带进去的资料，给出可以留意的健康方向、日常建议、
  来源链接，以及值得向医生确认的问题。
- **问诊引导（interview）**：先说一段情况，AI **一次只问一个问题**帮你补齐信息；追问
  不给方向、科室或来源，只收集事实；答完（或点「结束追问」）后可把问答存成一条症状记录，
  或加入待问清单、摘成资料。

每次外发前都会先弹出「将要发送的内容」预览，由你确认后才发送。发送范围仅包含脱敏后的
档案摘要、你选定的记录摘录、启用中的记忆与当前对话。若本机代理没开或出错，不会编造
内容，而是改用本地整理，并在界面上如实说明原因。

### 权威来源

问诊建议里展示的来源会经过权威域名白名单筛选：只有命中白名单的域名才会被当作来源展示，
命中不了就如实说明「未找到权威资料，请向医生确认」，不拿普通网页凑数。白名单在 `server/config.json`
的 `authorityDomains` 里配置，留空则回退到内置的默认清单（覆盖卫生健康、疾控、药品监管、
医学学会、三甲医院官网示例与诊疗手册等类别）。

### 无障碍

- 全局字号 14 到 32 连续可调（默认 14），由单页工作台宿主统一持有、跨功能区即时生效；
  8 个路由页同样生效。
- 高对比模式，方便在强光下或视力较弱时阅读。

## 小程序运行步骤

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，
   选择「导入项目」，目录选择本 `hospital-ai-miniapp` 文件夹，AppID 用测试号即可。
2. 若要用 AI 功能，先在仓库根目录启动本机代理（见根 `README.md` 的运行说明）。
3. 在开发者工具右上角「详情」→「本地设置」勾选「不校验合法域名」，以便小程序能访问
   `http://127.0.0.1:8787`。
4. 首次使用 AI 前，到「设置」→「AI 外部调用」打开开关，并在弹窗里阅读发送范围后同意。
5. （可选）在开发者工具的开发环境下，「设置」页会多出一个「演示模式」开关：打开后 AI
   输出为本地固定内容，全程不发任何网络请求，适合截图与演示。正式发布版不显示该开关。

## 隐私与数据边界

- **本地优先**：所有记录默认只存在本机，无需登录，也不上传到云端账号。
- **发送可控**：外部 AI 调用默认关闭；打开前需先同意说明；每次发送前都有预览；可随时关闭。
- **脱敏**：发送前对姓名、手机号、证件号做固定规则的脱敏替换。
- **出口唯一**：只允许访问本机回环地址（`127.0.0.1` / `localhost`），其它地址一律拒绝。
- **可清除**：设置页可导出或清除全部本地资料、附件、本机导出文件与记忆。
- **配置自持**：代理的模型与检索配置由你自己填写在本机 `server/config.json`，该文件不入库，
  仓库里只有示例文件，不含任何完整的明文密钥（历史文档中曾出现可定位账号的凭证标识，
  须按 `docs/SECURITY-REVOKE.md` 吊销）。

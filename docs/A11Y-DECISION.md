# 无障碍决策（A11Y Decision）

任务 16「大字模式全局应用与语音输入提示」的决策记录。本文件只描述**本工具实际采用**的
无障碍能力、实现机制与已知取舍；不记录未来方案的承诺。

## 1. 范围

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 全局字号缩放（14–32） | 已实现 | 8 个页面随 `AppPreferences.fontSize` 缩放 |
| 高对比模式 | 已实现 | `AppPreferences.highContrast` 一键切换 |
| 语音输入提示（零权限） | 已实现 | 仅文案提示，不申请麦克风权限 |
| 朗读（TTS） | **不实现**（决策） | 见 §3 |

## 2. 字号缩放与高对比机制

- **单一机制**：`hospital-ai-miniapp/shared/ui/a11y.ts` 从 `records.preferences` 读取
  `fontSize` / `highContrast`，由每个页面在 `onShow()` 调用 `syncA11y(this)` 写入本页
  `data`。
- **页面消费**：8 个页面（home/profile/symptoms/notes/questions/brief/ai/settings）的根节点
  统一写 `style="--mhp-scale: {{scale}}"`（`scale = fontSize / 14`，14 → 1、32 → 32/14），
  高对比再叠加 `is-hc` 类。
- **字号来源**：所有页面字号一律写成 `calc(Nrpx * var(--mhp-scale))`，**不写死 px**；
  `app.wxss` 只提供 `--mhp-scale` 默认值与设计令牌，不散落具体字号。
- **高对比来源**：`app.wxss` 定义全局 `.is-hc` 变量映射（把语义令牌指向 `--mhp-hc-*`），
  页面内 `color`/`background` 经 `var(--*)` 自动切换；settings 页保留其等价的
  `.settings.is-hc` 作用域块（值相同）以兼容既有契约。
- **未来页面**：D/F 波新增页面只要 `data` 展开 `A11Y_DATA`、`onShow` 调 `syncA11y(this)`、
  根节点加同样的两段绑定即可复用，无需各自读偏好。

## 3. 不做朗读（TTS）的决策

**决策：本工具不实现朗读 / 语音合成（TTS）。**

理由：

1. 朗读需要接入第三方语音合成插件，并伴随额外的权限申请与数据外发面；本工具定位为
   **本地优先**的个人就医准备辅助，默认不引入麦克风 / 音频相关权限与第三方语音依赖。
2. 计划的拒绝清单明确排除「第三方语音：TTS/ASR 依赖与朗读实现」；本任务据此不做朗读。
3. 用户的语音输入诉求由 §4 的零权限方案覆盖（系统键盘自带的语音输入），无需本工具
   自行采集音频。

## 4. 语音输入提示 = 零权限方案

- 采用 `config/texts.ts` 的 `A11Y.keyboardMic`（单一文案来源）：
  「可使用键盘话筒输入：语音由系统键盘提供，本工具不申请麦克风权限，使用前请确认你已知晓。」
- 展示位置：设置页「显示与无障碍」分组内的「语音输入」说明行（纯文案，无可操作控件）。
- **零权限**：本工具不调用任何 `wx.*` 录音 / 语音识别接口，也不在 `app.json` 声明麦克风或
  语音相关权限；语音由系统键盘自身提供，是否启用完全由用户在输入法侧决定。

## 6. 已知取舍（Accepted Debt）

- **验证粒度**：本次对 14 / 32 双档字号的差异以真实运行截图（`artifacts/screenshots/
  a11y-14.png`、`a11y-32.png`）的 md5 不同作为「可见差异」的客观代理；DevTools 自动化
  不提供逐元素文字溢出测量，故「无溢出」以**缩放面静态扫描（零裸 px）+ 运行时页面可渲染
  无异常**组合作为代理证据（见 `artifacts/qa/16-failure.txt`），不做像素级溢出断言。
- **历史遗留页**：仓库内存在未在 `app.json` 注册的旧页面（chat/dashboard/doctors/elderly/
  login），它们含写死的 px 字号；它们**不在本次 8 个正式页面范围**，未纳入缩放面，后续如
  启用需单独迁移。
- **原生控件**：`slider` / `switch` 等原生控件不读取 CSS 变量，其强调色在 settings 页通过
  内联 `activeColor` 镜像（既有实现），不随 `--mhp-scale` 缩放。

## 1 软件简介

### 1.1 软件用途

「就医准备助手」是一个运行在手机上的个人健康信息记录与整理工具，帮助你：

- 随手记下症状、资料摘录与想问医生的问题，**全部只保存在本机**；
- 出门前把散落的信息收拢成一份条理清楚、可复制、可导出图片的**就医摘要**；
- 需要时，借助你自己电脑上的 AI 代理，把口语化的描述整理成要点，或梳理可以留意的
  健康方向、日常建议与值得向医生确认的问题。

### 1.2 软件定位与重要声明

- 本软件**不是医疗器械**，不做任何医疗判断，不提供确诊、处方、用药或疗效类结论。
- AI 生成的内容仅用于帮助你**把信息说清楚**，不能替代执业医务人员的当面判断，
  也不作为任何医疗决定的依据。
- 如出现突然或严重的不适，请立即寻求线下医疗帮助，不要只依赖本工具自行处理。

### 1.3 软件组成

| 组成 | 说明 | 是否必需 |
| --- | --- | --- |
| 微信小程序 | 记录、整理与展示界面（本手册主要说明对象） | 必需 |
| 本地 AI 代理 | 运行在你电脑上的小程序服务，AI 功能经它转发 | 仅使用 AI 功能时需要 |

## 2 运行环境与安装

### 2.1 环境要求

| 项 | 要求 |
| --- | --- |
| 小程序载体 | 微信开发者工具（用于导入与运行本小程序） |
| AppID | 使用**测试号**即可（项目配置中为 `touristappid`） |
| 代理运行环境（可选） | Node ≥ 24（代理直接以 Node 运行 TypeScript，无需构建） |
| 网络 | 代理仅监听本机回环地址 `127.0.0.1:8787`，仅本机可访问 |

### 2.2 安装与打开小程序

1. 安装并打开**微信开发者工具**。
2. 选择「**导入项目**」。
3. **目录**选择本项目中的 `hospital-ai-miniapp` 文件夹（即包含 `project.config.json` 的目录）。
4. **AppID** 选择「测试号」。
5. 导入后点击「**编译**」即可看到小程序界面（快捷键 `Ctrl+B`）。
6. 打开调试器：点击底部工具栏的「**调试器**」，或用菜单「**调试 → 打开调试器**」，
   可查看 Console / Network / Storage / WXML 等面板。

> 开发调试提示：若需查看本机存储内容，可在调试器的 **Storage** 面板查看 `mhp_` 前缀的键。

### 2.3 准备本地 AI 代理（仅使用 AI 功能时需要）

1. 在项目根目录执行：

   ```bash
   cp server/config.example.json server/config.json
   ```

2. 编辑 `server/config.json`，填入你自己的模型服务配置（`llm`）与可选的检索服务配置（`search`）；
   两项 `apiKey` 均可留空，此时代理照常启动，但 AI 相关能力不可用。
3. 启动代理：

   ```bash
   npm run dev:api
   ```

   启动后监听 `http://127.0.0.1:8787`，并打印端口与就绪状态。
4. 健康检查：

   ```bash
   curl http://127.0.0.1:8787/api/health
   # => {"ok":true,"providerReady":true,"searchReady":false,"demo":false}
   ```

5. **务必**在微信开发者工具右上角「**详情 → 本地设置**」勾选
   「**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**」，
   否则小程序无法访问本机代理。

> 说明：`server/config.json` 不会被纳入版本管理；仓库中只保留示例文件，不含任何密钥。

## 3 首次启动与快速开始

### 3.1 首次启动：隐私保护提示

首次打开（或隐私说明版本更新后）会弹出「**隐私保护提示**」，说明：

- 你的记录默认只保存在本机，不会自动上传；
- 外部 AI 调用默认关闭，只有你主动开启并同意后才会使用；
- 开启外部 AI 前会再次说明发送范围，你可以随时关闭；
- 你可以随时一键清除全部本地数据，或把数据导出备份。

点「**我同意**」进入软件；点「**退出**」则退出小程序。

### 3.2 快速开始

1. 进入「**工作台**」；左侧导航栏列出全部功能，点击「**个人档案**」填写称呼、年龄段、过敏与长期用药等；
2. 点左侧导航栏「**症状记录**」记下第一条症状；
3. 点左侧导航栏「**资料摘录**」把化验单等资料的关键内容抄录下来；
4. 点左侧导航栏「**待问清单**」记下想问医生的问题；
5. 点左侧导航栏「**就医摘要**」勾选要纳入的记录，生成摘要并复制或导出图片。

## 4 功能操作说明

页面左侧是**可折叠导航栏**（`components/app-sidebar`，全局注册于 `app.json`），列出全部 8 个页面：
工作台、个人档案、症状记录、资料摘录、待问清单、就医摘要、AI 助手、设置；点击即切换，底部「« / »」可收起为纯图标栏。
工作台自身只展示概览信息（产品定位、准备总览、记录概览、最近记录、使用提示），不再重复列出功能入口。本章按页面逐一说明。

### 4.1 工作台

![工作台（默认字号 14）](../artifacts/screenshots/soft-copyright/home-14.png)
![工作台（大字模式 32）](../artifacts/screenshots/soft-copyright/home-32.png)

**界面说明**

- **左侧导航栏**：可折叠，列出全部 8 个页面；收起后为纯图标栏，切换时当前页高亮，状态本机记忆。
- **问候语与日期**：按本机时间显示「早上好 / 中午好 / 下午好 / 晚上好 / 夜深了」，
  已建立档案时会拼接称呼；问候语同行右侧显示本机日期（如「10月3日 周六」），下方一句话说明这个软件做什么。
- **准备总览**：大号显示「已完善 X / 5 项」与进度条，并给出提示语，右侧为「去完善 / 去看看」；

- **最近记录**：合并症状、资料、待问三类记录后按更新时间倒序，最多显示最近 5 条；
  无记录时显示空态文案与「记一条症状」按钮。
- **使用提示**：卡片显示固定安全提示句与本地优先说明（数据只存在本机）。

| 点左侧导航栏任一项 | 跳转到对应页面；当前页在导航栏中高亮 |
| 点导航栏底部「« / »」 | 导航栏在展开 / 收起（纯图标）之间切换，状态本机记忆 |
| 尚未添加任何记录时查看「最近记录」 | 显示空态文案「还没有记录。从记下第一段身体感受开始。」与「记一条症状」按钮 |

### 4.3 症状时间线

![症状时间线（14）](../artifacts/screenshots/soft-copyright/symptoms-14.png)
![症状时间线（32）](../artifacts/screenshots/soft-copyright/symptoms-32.png)

**界面说明**

- 记录按**发生时间倒序**展示为时间线，逐条显示原话、持续时长、影响、标签与附件名。

**操作步骤**

### 4.6 就医摘要

![就医摘要（14）](../artifacts/screenshots/soft-copyright/brief-14.png)
![就医摘要（32）](../artifacts/screenshots/soft-copyright/brief-32.png)

**界面说明**

- 「选择记录」区按症状时间线、资料摘录、待问问题三类列出可纳入的记录；
  个人档案（称呼、年龄段、过敏、长期用药、既往情况）如有内容会在生成时自动带上。
- 摘要按**固定小节顺序**汇总：称呼/年龄段 → 症状时间线 → 用药 → 过敏/既往 →
  资料摘录 → 待问问题；**症状行逐字保留你填写的原话**；缺失的小节整体省略，不补写。

**操作步骤**

1. 勾选要纳入的记录（可点「**全选**」或「**清空选择**」）；
2. 点「**生成摘要**」，编辑区出现可编辑的摘要内容；
3. 如需修改，直接在编辑区编辑；
4. 可点「**复制**」把摘要文本写入剪贴板；
5. 可点「**生成图片**」得到 750×1334 的摘要图片，再「**保存到相册**」或「**分享**」；
6. 点「**保存**」把摘要写入本机。

**预期结果**

| 情形 | 结果 |
| --- | --- |
| 未选择任何记录就点「生成摘要」 | 提示「请先选择至少一条记录」 |
| 生成成功 | 编辑区显示摘要，并有两条说明：<br>「症状时间线」逐字保留你填写的原话，未做改写。<br>其余内容为按你选择的记录整理而成，属于整理内容，就诊时请与医生确认。 |
| 点「复制」 | 提示「已复制摘要」 |
| 点「生成图片」→「保存到相册」 | 生成 750×1334 图片；保存成功提示「已保存到相册」 |
| 相册权限被拒 | 提示「需要相册权限」，可点「**去设置**」开启后重试 |
| 点「保存」 | 摘要写入本机，页面显示「导出时间」 |

### 4.7 AI 助手

![AI 助手 · 资料整理模式（14）](../artifacts/screenshots/soft-copyright/ai-14.png)
![AI 助手 · 资料整理模式（32）](../artifacts/screenshots/soft-copyright/ai-32.png)
![AI 助手 · 问诊建议模式（14）](../artifacts/screenshots/soft-copyright/ai-consult-14.png)
![AI 助手 · 问诊建议模式（32）](../artifacts/screenshots/soft-copyright/ai-consult-32.png)

**界面说明**

- 顶部**状态条**反映当前状态：外部 AI 未开启 / 已开启待发送 / 上次发送成功 /
  本地代理未连接（已改用本地整理）/ 演示模式。
- 页面含常驻的**安全提示**与非诊断免责说明。
- 两种模式卡片：**资料整理** 与 **问诊建议**。
- 输入区下方显示已带入的记忆条数，可点「管理记忆」跳到设置页。

**两种模式**

| 模式 | 输出内容 |
| --- | --- |
| 资料整理 | 要点 / 提取（症状、用药、过敏、既往、检查）/ 待补充 / 可以问的问题 |
| 问诊建议 | 健康方向 / 建议就诊科室 / 来源链接 / 日常建议 / 待补充 / 可以问的问题 / 免责声明 |

**操作步骤**

1. 从左侧导航栏进入「**AI 助手**」，选择「资料整理」或「问诊建议」（或在本页点击模式卡片切换）。
2. **首次进入问诊建议模式**时会弹出「**使用问诊建议前请确认**」，说明发送范围与
   自动提炼说明；点「**我同意**」继续，点「**先不用**」则保持原模式。
3. 在输入框填写内容（例如：最近一周晚上睡不好，白天没精神）。
4. 问诊建议模式下可展开「**带入我的资料**」，勾选要作为上下文的记录；
   可开启「**附带档案摘要**」。未勾选的内容不会离开本机。
5. 点「**发送**」，弹出「**发送前确认**」面板，按段展示**将要发送的内容**
   （档案摘要 / 记录摘录 / 记忆 / 对话）。
6. 确认后点「**确认发送**」；点「**取消**」则不发送。

**预期结果与降级行为**

| 情形 | 结果 |
| --- | --- |
| 未开启外部 AI 就点「发送」 | 弹出引导「外部 AI 未开启」，可点「**去设置**」前往开启；本次仅在本地处理（已开启「演示模式」时不受此限，直接出结果） |
| 发送成功（资料整理） | 显示要点、提取、待补充、可以问的问题等分块结果 |
| 发送成功（问诊建议） | 每条健康方向与日常建议带「来源：<标题> · <域名>」并附链接 |
| 本次未命中权威来源 | 在来源位置显示提示「**未找到权威资料，请向医生确认**」 |
| 本机代理未启动或出错 | 显示降级状态条并如实说明（例如「本地代理未启动或未开启。你仍可使用本地整理功能，内容不会上传。」）；点击「**重试连接**」可重试；下次发送自动改用**本地整理**（无网络），**绝不编造** AI 内容 |
| 输出未通过安全校验 | 提示「外部 AI 的回复未通过安全校验，已改用本地整理。」并降级为本地整理 |
| 点「**改用本地整理**」 | 直接用本地整理引擎处理当前内容，不联网 |

**结果回流**

| 操作 | 预期结果 |
| --- | --- |
| 对 AI 结果点「**存为记忆**」 | 保存为一条偏好记忆（提示「已存为记忆」；已存在时提示「这条已经在记忆中」） |
| 对 AI 结果点「**存为资料**」 | 打开「保存为资料摘录」表单，确认后保存到「资料摘录」 |
| 对 AI 结果点「**加入待问清单**」 | 把结果中的问题加入待问清单（自动去重） |

## 5 隐私与数据边界

| 边界 | 说明 |
| --- | --- |
| **本地优先** | 所有记录默认只存在本机，无需登录，也不上传到云端账号 |
| **发送可控** | 外部 AI 调用默认关闭；开启前需先同意说明；每次发送前都有预览；可随时关闭 |
| **脱敏** | 发送前对姓名、手机号、证件号做固定规则的脱敏替换 |
| **出口唯一** | 只允许访问本机回环地址（`127.0.0.1` / `localhost`），其它地址一律拒绝 |
| **可清除** | 设置页可导出或清除全部本地资料、附件与记忆 |
| **配置自持** | 代理的模型与检索配置由你自己填写在本机 `server/config.json`，该文件不入库，仓库里只有示例文件 |

## 6 常见问题

**Q1：发送后提示「外部 AI 未开启」，怎么办？**
到「设置 → AI 外部调用」打开「允许外部 AI 调用」，在弹窗中点「我同意」。

**Q2：提示「本地代理未启动或未开启」，怎么办？**
请在电脑上启动本地代理（项目根目录执行 `npm run dev:api`），然后回到 AI 页点「重试连接」。
若不打算使用外部 AI，可直接点「改用本地整理」，功能仍然可用且不联网。

**Q3：AI 结果里没有「来源链接」或「健康方向」？**
说明本次没有命中权威来源。此时界面会显示「未找到权威资料，请向医生确认」，
这是设计好的行为，不会用普通网页或模型自述凑数。

**Q4：真机预览时 AI 功能不可用？**
本软件的代理只监听本机回环地址，**真机无法访问 `127.0.0.1`**。因此 AI 功能与演示截图
仅在微信开发者工具环境中成立；真机上是纯本地的记录与整理体验。

**Q5：不想配置任何模型，能看看 AI 的效果吗？**
可以。在微信开发者工具中打开「设置 → 演示模式」即可（**这一个开关就够，无需再开「允许外部 AI 调用」**），
AI 输出会改为本地固定内容，同一输入永远得到同一结果，全程不发起任何外部请求。

**Q6：字号太小看不清？**
在「设置 → 显示与无障碍」拖动「字号」滑条（14–32），8 个页面都会随之缩放；
强光下可再打开「高对比模式」。

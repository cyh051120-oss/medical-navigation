# 安全凭证吊销指引（Legacy Credential Revoke）

## 背景

旧版本客户端曾在 `hospital-ai-miniapp/config/api.js` 中明文内置第三方 AI / 语音服务的凭证。
这些值已随本地 Git 历史被提交（属当时批准的设计），仓库为**仅本地、从未 push**，但
按安全基线，一旦进入版本历史即应视为**已泄露（compromised）**，必须吊销重建。

任务 2 已将该文件存根化（`module.exports = {}`），此后代码不再引用任何第三方密钥。
**存根化不等于吊销**：密钥本身仍然有效，必须由用户在对应控制台手动吊销。

### 操作步骤

1. 登录 **火山引擎控制台** `console.volcengine.com`，进入 **API Key 管理**，找到掩码为
   `9573****` 的 Key，执行**吊销**；进入 **方舟 → 推理接入点**，清理两个 `ep-2026****` 接入点。
2. 登录 **百度智能云控制台** `console.bce.baidu.com`，进入 **语音技术 → 应用管理**，
   找到掩码为 `I8EQ****` / `qVZc****` 的 AK/SK，执行**重置**或删除该应用并**新建应用**。
3. 吊销/重建完成后，若后续确需接入，请将新凭证存放在仓库**之外**（环境变量或未纳入版本控制的
   本地配置文件），**切勿**重新下载或写回本仓库。

## 禁止事项

- 不得在本仓库任何文件（含文档、证据）中写入完整凭证值。
- 不得从本地 Git 历史中"恢复"旧凭证。
- 不得将本仓库 push 到任何远端。
